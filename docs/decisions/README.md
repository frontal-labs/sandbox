Each decision follows this template:

```markdown

YYYY-MM-DD

Link to benchmark code/results

## Options Compared
| Option | Metric 1 | Metric 2 | Metric 3 |
|--------|----------|----------|----------|
| A | | | |
| B | | | |

## Decision
Chosen option and rationale

## Follow-up
- Re-evaluate when: (condition)
- Metrics to watch:
```
