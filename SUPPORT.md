# Support

## How to Get Help

Open an issue at [github.com/frontal-labs/sandbox/issues](https://github.com/frontal-labs/sandbox/issues)
for bugs, design questions, and feature requests.

When reporting a bug, include the session tier, command or API operation, host
platform, expected behavior, actual behavior, and relevant logs. Do not include
credentials, customer data, or secrets.

## Security

Do not disclose security vulnerabilities in a public issue. Contact
[security@frontal.dev](mailto:security@frontal.dev) with reproduction details.

See [SECURITY.md](SECURITY.md) for the coordinated disclosure policy.

## Project direction

Frontal Sandbox is an execution platform for AI agents: isolate-first sessions,
capability-checked access, copy-on-write filesystems, snapshots, and explicit
promotion to QEMU microVMs.
