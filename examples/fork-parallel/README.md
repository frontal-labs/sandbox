# Frontal Sandbox Fork Parallel Example

Demonstrates the `fork-parallel` workflow using the Frontal Sandbox TypeScript SDK.

## Prerequisites

- Node.js 20+
- A running Frontal Sandbox server (default `http://localhost:8080`)

## Run

```bash
npm install
npm start
```

## Environment

- `SANDBOX_BASE_URL` (default `http://localhost:8080`)
- `SANDBOX_API_KEY` (optional)
